UPDATE: Crossbreeder Plus v1.0.11 - With R1 support!

By Andrea Coppini

Key features

  • RUCKUS One integration: Automatically imports APs from selected RUCKUS One venues.
  • Automatic AP password retrieval: Retrieves each AP's current, RUCKUS One-managed CLI password.
  • Expanded inventory: Captures configured country codes and identifies APs with locked country codes.
  • Multi-command execution: Runs multiple CLI commands sequentially within one SSH session.
  • Improved firmware operations: Supports model-based firmware templates and prevents conflicting reboot/reset actions during firmware updates.
  • Version notifications: Alerts users when a newer Crossbreeder release is available.
  • Improved factory-default onboarding: Better handles forced password changes and default Unleashed setup prompts.
